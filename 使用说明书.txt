                PDF 水印批量删除助手 - 使用说明书 (Pro V0.2)
================================================================

本工具专注于 PDF 的水印识别与精准清除，支持以下核心功能：
- 全可视化对象点选与框选删除（推荐）
- 矢量对象与图形深度清理
- 本地图像离线修复
- 云端 AI 背景修补（需配置 API Key）

免责声明：
本工具仅供个人学习、研究、档案整理使用。请勿用于侵权、绕过版权保护或其他非法用途。

----------------------------------------------------------------
【一分钟快速上手】
----------------------------------------------------------------
1. 把待处理的 PDF 或图片文件放进 [input] 文件夹。
2. 双击运行 [一键启动_Mac.command]。
3. 在弹出的菜单中输入模式编号（推荐输入 1 使用可视化模式）。
4. 处理完成后，结果会自动保存在 [output] 文件夹中。

----------------------------------------------------------------
【项目目录说明】
----------------------------------------------------------------
input/           ← [输入] 放待处理的文件。
output/          ← [输出] 存放处理后的成品。
done/            ← [归档] 处理成功后的原文件会自动移至此处。
core/            ← [引擎] 处理 PDF 结构、矢量、对象的核心代码。
gui_app/         ← [界面] 可视化 Pro 版的 UI 代码。
utils/           ← [工具] 配置管理和通用工具。
requirements.txt ← [依赖] 环境所需的库列表。

----------------------------------------------------------------
【模式选择指南】
----------------------------------------------------------------
1. 🖥️ 可视化智能清理 (Pro - 强烈推荐)
   - 适合：99% 的 PDF 场景，尤其是复杂 Logo 或不知道水印是什么的情况。
   - 特点：所见即所得。双击水印即可选中，支持右键“全书同步删除”。
   - 操作：支持【对象点选】和【区域框选】（针对无法选中的 Logo 水印）。

4. 🪄 AI 图像修补 (Cloud Mode)
   - 适合：背景极其复杂的扫描件 PDF。
   - 特点：利用阿里云 DashScope 大模型进行“像素级”修补。
   - 注意：需在 [7.系统设置] 中配置 API Key。

5. ☢️ 核弹模式 (Vector Killer)
   - 适合：普通方式删不掉的背景网格、灰色线条、顽固矢量图形。
   - 特特点：直接从 PDF 底层协议层面强行剥离指定特征的图形对象。

6. 🖼️ 本地图片模式 (Offline)
   - 适合：纯图片、扫描版 PDF。
   - 特点：全离线处理，通过图像算法快速漂白背景、去除杂色。

7. ⚙️ 系统设置
   - 用途：设置阿里云 DashScope API Key。

----------------------------------------------------------------
【可视化模式 (模式 1) 使用技巧】
----------------------------------------------------------------
- [对象点选]：默认模式，鼠标划过水印会出现红框，双击选中，变白即代表删除。
- [区域框选]：如果水印是由无数小点组成的 Logo（如“快乐学习”），请切换到框选模式，手动拉一个框罩住它。
- [全书同步]：右键点击选中的水印，选择“应用到所有页”，程序会自动寻找全书相同的水印并一键擦除。
- [快速保存]：标记完后点击“⚡ 快速保存”，程序会直接在原文件夹生成新文件，省去选路径的麻烦。

----------------------------------------------------------------
【常见问题 FAQ】
----------------------------------------------------------------
Q1：运行后提示没有文件？
A：请确认文件已放入根目录的 [input] 文件夹中，且后缀名为 .pdf, .jpg, .png。

Q2：图片模式处理后不能选中文字了？
A：这是正常现象。模式 6（本地图片模式）会将 PDF 渲染成图片再处理，因此会丢失文本层。如果需要保留文字，请优先使用模式 1。

Q3：如何获取 AI 修补所需的 API Key？
A：访问阿里云百炼平台 (https://bailian.console.aliyun.com/) 申请 DashScope 密钥。
