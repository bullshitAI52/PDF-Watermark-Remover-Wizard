                 PDF 水印清理助手 - 使用说明书
================================================================

本工具用于个人学习、研究和档案整理。请仅处理您有权处理的文件。

----------------------------------------------------------------
【快速开始】
----------------------------------------------------------------
1. 双击根目录的「一键启动_Mac.command」。
2. 启动菜单直接按回车，进入推荐的「可视化智能清理」。
3. 在左侧点击「选择 PDF…」，或从 input/ 文件列表打开文件。
4. 双击页面上的水印对象进行标记；无法点选时切换为「区域框选」。
5. 如需处理整本书，点击「将已标记水印同步至全书」。
6. 点击「导出到 output 文件夹」，结果保存为
   output/原文件名_cleaned.pdf。

----------------------------------------------------------------
【推荐模式：可视化智能清理】
----------------------------------------------------------------
适用于绝大多数文字、图片及常规对象水印，能保留 PDF 的文本层。

操作说明：
- 点选对象：鼠标移动到对象上会出现边框，双击即可标记或取消标记。
- 区域框选：拖拽框出水印区域，程序会标记框中的可识别对象。
- 自由涂除：仅当需要覆盖无法识别的水印时，在「高级匹配设置」中开启。
  此操作可能遮挡框内正常内容，请谨慎使用。
- 全书同步：先在任意页面标记一个或多个样本，再同步到全书；可随时取消。
- 保存：Cmd/Ctrl + S 可快速导出；也可使用「另存为…」指定位置。

常用快捷键：
- ← / →：上一页 / 下一页
- + / -：放大 / 缩小
- Tab：在重叠对象之间切换
- Esc：取消正在进行的全书同步

----------------------------------------------------------------
【其他模式】
----------------------------------------------------------------
AI 图像修补（云端）
适用于复杂扫描件或背景水印。需要在「系统设置」中配置 DashScope
API Key；上传文件至云端前，请确认您有权这样做，并留意服务费用。

本地图片清理
适用于扫描件和图片，完全离线。它会把页面转换为图像，可能丢失
PDF 原有的可搜索文本层。

矢量强力清理
用于普通方式无法清除的矢量线条、底纹或图形。该模式会批量处理
input/ 中的 PDF，可能误删正文图形；请先备份原文件并逐页检查 output/
中的结果。

----------------------------------------------------------------
【常见问题】
----------------------------------------------------------------
Q：检测不到水印对象？
A：水印可能已嵌入扫描图片。可使用可视化清理的区域框选，或尝试本地图片清理。

Q：同步后没有匹配到其他页面？
A：不同页面的水印位置、大小或内容差异过大时，建议在各类页面分别标记。

Q：导出后原文件会被覆盖吗？
A：不会。默认会在 output/ 生成新的 cleaned 文件；如文件名重复，请先
   另存为或检查已有输出文件。

Q：为什么图片模式后不能搜索文字？
A：图片模式会重新渲染页面，因此不保留原 PDF 的文本层。需要保留文字时，
   请优先使用可视化清理。
