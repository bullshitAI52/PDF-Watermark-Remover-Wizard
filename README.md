# 🎨 PDF Watermark Remover Wizard (Pro V0.2)

基于 Python 的 PDF 批量去水印工具。采用取证级分析与多引擎处理，支持可视化对象点选、区域框选、矢量清理及 AI 修补。

## 🌟 核心亮点 (Key Features)

1.  **🖥️ 可视化 Pro 界面**: 所见即所得，双击水印即可删除，支持框选复杂 Logo。
2.  **🌍 全书同步匹配**: 选中一个水印，自动识别并清除全书数百页的相同对象。
3.  **🪄 AI 图像修补**: 针对扫描件、复杂背景，利用云端大模型进行像素级修复。
4.  **☢️ 矢量核弹模式**: 强力剥离 PDF 底层矢量路径、网格、灰度线条。
5.  **⚡ 极简工作流**: 放入文件 -> 一键启动 -> 可视化标记 -> 快速导出。

## 📁 目录结构

- **`core/`**: 核心处理引擎（ObjectEngine, VectorKiller）。
- **`gui_app/`**: V2 专业版桌面 UI 界面。
- **`image_mode_pic_watermark/`**: 离线图片模式与 AI 修补逻辑。
- **`utils/`**: 统一配置管理（API Key）与文件工具。
- **`input/`**: 📥 待处理文件存放处。
- **`output/`**: 📤 处理结果输出目录。

## 🖥️ GUI 可视化界面使用手册

启动 `gui_app/main_v2.py` 后，你会看到三栏布局：左侧侧边栏、中央画布、顶部状态栏。

### 基本流程

```
放入 PDF → 打开文件 → 标记水印 → 全书同步(可选) → 导出
```

### 第一步：打开 PDF

1. 左侧 **📁 Input Files** 列表会显示 `input/` 文件夹下的所有 PDF
2. **点击**文件名，文件加载到中央画布

### 第二步：标记水印（删除指定页）

**对象点选模式（默认）**

- 页面上被检测到的对象会用 **蓝色框** 标出
- **鼠标悬停** → 蓝色框变红色
- **双击**红色框 → 标记为要删除的水印，框变**红色填充**
- 再**双击**已标记的 → **取消标记**

**区域框选模式**

- 点击侧边栏 **⬜ 区域框选** 切换到框选模式
- 在画布上**按住拖拽**拉出一个绿色虚线框
- 松开鼠标 → 框内所有对象一次标记

> 💡 **只删除某一页**：只在该页标记，不要点"全书同步"，然后直接导出即可。

### 第三步：全书同步删除（所有页）

- 先在**某一页**标记 1-2 个水印对象
- 点击 **🌍 全书同步删除**
- 弹出确认框 → 点击 **确认同步**
- 程序会在全部页面中查找**相同位置、相同大小、相同内容的**对象并标记
- 状态栏显示进度：`⏳ 全书同步中 (45/180 页)...`
- 完成后自动刷新页面，同步标记的对象会显示红色填充

> ⚠️ 匹配条件比较严格：位置±5px、大小±2px、文字完全一致。如果水印在不同页位置有偏移，可以只手动逐页标记。

### 第四步：导出

- **📥 导出到 output 文件夹** → 自动保存到 `output/原文件名_cleaned.pdf`
- **💾 另存为…** → 自行选择保存位置和文件名

### 常见问题

**Q: 检测不到水印（页面上没有蓝色框）？**  
A: 水印可能是扫描件中的图片，不是可解析的 PDF 对象。这种情况切换到**区域框选模式**，手动圈出水印区域。

**Q: 全书同步找不到任何匹配？**  
A: 水印在不同页的位置/大小有变化时，同步匹配可能会失败。可以逐页手动双击标记后导出。

**Q: 页面水印太多，框选很慢？**  
A: 先双击标记一两个关键水印，再用全书同步自动匹配所有页，速度最快。
